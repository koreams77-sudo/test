# 레포지터리 테스트용

## 해당 레포지터리에서 1회만 실시

아래와 같은 내용을 테스트 합니다.
- 디렉터리(폴더) 생성
- 로컬 레포지터리 생성 및 초기화: git init
- 로컬 저장소에 목적지인 원격 저장소 지정: git remote add origin "깃허브레포지터리주소"
- 보안 정보(토큰) 등록: url = https://github계정:발급받은_토큰_값@레포지터리주소


---------------------------------------------

## 매 작업시 마다 Push

아래 내용은 매 작업시 마다 진행합니다.
- 코딩 및 작업
- 작업 내용 등록: git add 작업파일명
- 작업 내용에 관한 메시지 등록: git commit -m "메시지 내용"
- 원격 저장소(레포지터리)에 배포: git push -u origin 브랜치명


## 매 작업시 마다 pull
아래 작업을 먼저 선행되어 있어야하며, 최초 1회만 합니다.
- 로컬 레포지터리 초기화: git init
- 원격 저장소 지정: git remote add origin "레포지터리 주소"

아래 내용은 매번 필요시
- git pull 레포리지주소 브랜치명
